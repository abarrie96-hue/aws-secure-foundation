# AWS Secure Foundation

## Project Overview

This project establishes a secure AWS foundation following cloud engineering and security best practices.

## Objectives

- Secure the AWS account
- Configure IAM
- Enable MFA
- Configure AWS CLI
- Enable CloudTrail
- Create budget alerts
- Prepare for Infrastructure as Code
